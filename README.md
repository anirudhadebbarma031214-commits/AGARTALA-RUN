# AGARTALA RUN 🏃‍♂️🛺

A free 2D, three-lane endless runner inspired by arcade runner mechanics and set in stylized Agartala, Tripura.

## Play
Open index.html in a browser, or enable GitHub Pages: Settings → Pages → Deploy from a branch → main / root.

## Features
- Four selectable Agartala-themed routes and five unlockable runners
- Coins, mystery gift rewards, shields and magnets
- Obstacles, jumping, sliding, lane switching and a chasing officer
- Funny text memes and synthesized arcade sound effects (no copyrighted samples)
- Touch/swipe and keyboard controls
- Saved wallet, unlocks and best score using localStorage

## Notes
Artwork is stylized canvas vector/emoji art, not photorealistic. All currency and gifts are in-game only. Audio starts after interaction due to browser restrictions.
